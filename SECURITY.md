# Security Policy

## Supported Versions

Project Synthesis 17 is an educational and engineering-learning project.
Security fixes are considered against the latest version on the default branch.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it
privately through GitHub's private vulnerability reporting mechanism.

Do not publicly disclose the vulnerability before it has been reviewed.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Relevant logs, screenshots, or proof of concept where appropriate

## Scope

The project demonstrates security mechanisms such as authentication,
authorization, password hashing, rate limiting, input validation,
event processing and audit logging.

These mechanisms are implemented for engineering and learning purposes.
The project is not intended to process real financial transactions or
serve as production banking infrastructure.
